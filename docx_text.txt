Error description36Overview This document describes the usage of the Cling Android Custom SDK, including various interface features and related data structures. This SDK supports all the smart watches and wristbands currently developed by HiCling, including Cling Band, Cling Leap, Cling Aura, Cling Thermo etc.There are several SDK functions described in this document,including authorizing devices, synchronizing device data, configure devices, and more. The SDK includes two major parts, network data transmission and local data processing. The respective functional modules will be described in detail below.HiCling DevicesCling LEAP（GPS Heart Rate Fitness Watch）Cling Aura(Smart Fitness Wristband)Cling Pace(Smart Running Wristband)Clingband UV(UV Fitness Wristband)Cling SAND(SAND Smart Wristband)Cling VOC(Multi-gas Fitness Wristband)Clingband NFC(NFC Fitness Wristband)Cling Classic(smart Fitness Watch)Cling Trink(Smart Location Tracker)Cling RainFlower(Customized device for Bank of nanjing)Cling Thermo(Smart Thermo Wristband)ETETH 07（Customized device for ETE Health Dubai UAE）SDK Use Flow The Cling Android Custom SDK requires a web server as the companion unit.
